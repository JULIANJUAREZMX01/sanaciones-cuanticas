# ADR-001: Sitio estático con consentimiento por fases

- **Estado:** Aceptada · **Fecha:** 2026-11-01

## Contexto
Se requiere un sitio informativo y de reservas para el Método Convergencia (Reiki + inducción personal + lenguaje cuántico) con estética folclórica mexicana (dragones rosas, colibríes, alebrijes) y un cuestionario de primer encuentro de 30 preguntas.

## Decisión
1. Astro estático en GitHub Pages: sin servidores ni costos recurrentes.
2. El cuestionario no se envía a ningún backend: se compone en el dispositivo y se envía por WhatsApp, protegiendo datos sensibles.
3. Disclaimer explícito en todas las páginas: no diagnostica, no cura, no sustituye tratamiento; el lenguaje cuántico se declara metáfora.
4. Criterios de pre-aprobación y aprobación documentados en `/metodo/`.
5. Paleta folclórica (rosa mexicano, rojo, jade, cempasúchil, cobalto) con ilustraciones alebrije generadas para el sitio.

## Consecuencias
- Confianza alta y riesgo legal bajo al no prometer resultados clínicos.
- Si más adelante se necesita agenda con pagos, se añade un servicio externo, no un servidor propio.
- Las ilustraciones deben sustituirse por fotografías reales cuando estén disponibles.
