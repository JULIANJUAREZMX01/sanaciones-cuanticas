# Sanaciones Cuánticas Energéticas · Método Convergencia

**Sitio en vivo:** https://julianjuarezmx01.github.io/sanaciones-cuanticas/

Sitio informativo y de reservas para el método creado por la **Lic. Dra. Rosa Patricia Alvarado Moreno**: Reiki + inducción personal + presencia a distancia, con consentimiento por fases y cuestionario de primer encuentro de 30 preguntas.

## Secciones
- `/` — presentación, tres pilares, fases, sesiones, consentimiento, creadora, FAQ
- `/metodo/` — documento del método, respuestas involuntarias observadas, criterios de aprobación
- `/sesiones/` — Armonización $600 · Sesión profunda $900 · Programa Convergencia $1,200
- `/cita/` — WhatsApp, llamada, videollamada y presencial (Calle Limón 618, Col. Chapultepec)
- `/cuestionario/` — 30 preguntas en 5 bloques; arma el mensaje y lo envía por WhatsApp desde el dispositivo
- `/aviso/` — qué es y qué no es, privacidad, cuándo se deriva

## Arquitectura
Astro estático, sin servidores ni servicios de pago, desplegado en GitHub Pages por workflow. CI con `astro check` + build. Gobernanza en `docs/` (ADR + investigación + calendario).

## Principios
1. Nada se hace sin consentimiento explícito por fase.
2. No se promete curación médica ni se diagnostica.
3. El lenguaje cuántico se usa como metáfora declarada, no como mecanismo terapéutico.
4. Los datos del cuestionario no viajan a ningún servidor: se envían desde el WhatsApp del consultante.
